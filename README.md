# Vania Halim — Portfolio

A full-stack portfolio landing page showcasing biotech automation, computational biology, and scientific communication work.

## Projects

- **scLIDER 2.0** — Interactive scRNA-seq analysis tool. Python/Scanpy with an intuitive slider interface for tunable parameters.
- **Closed-Loop Battleship** — Autonomous robotic system using a liquid handler (OT2), chemical indicators, and computer vision.
- **BattleSAT** — Z3 constraint solver that reconstructs ground-truth experimental boards from noisy readings.
- **Scientific Communication** — Validation study on cell-type annotation with technical writeup + visual presentation deck.

## Structure

```
.
├── index.html                    # Main portfolio page
├── BattleSAT Writeup.dc.html     # BattleSAT project details
├── OT2_Battleship.dc.html        # Closed-loop Battleship writeup
├── scLIDER Writeup.dc.html       # scLIDER project details
├── assets/                       # Images, GIFs, demos
└── uploads/                      # CKD presentation slides
```

## Viewing

- **Local**: Open `index.html` in any modern browser.
- **Online**: Deploy via GitHub Pages — set repo to use `main` branch as source in Settings > Pages.

## Technology

Built with Design Components (`.dc.html` — self-contained HTML files with no build step required). Each page is a standalone, streaming HTML artifact.
