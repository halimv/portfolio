scLIDER 2.0

Interactive scRNA-seq analysis made easy.

Go from a counts matrix to UMAP/t-SNE in just a few clicks with an interactive interface for visualizing single-cell RNA sequencing data. Sliders with pre-configured defaults and bounded input ranges for tunable parameters lets you focus on exploring key analytical decisions without wrestling tutorials or code. 

The original version was written in Go and included Seurat validation scripts in R with an RShiny interface. While Go was ideal for learning low-level pipeline mechanics, Python/Scanpy allows for an enhanced user experience.

CLOSED-LOOP BATTLESHIP

Play battleship on a liquid handler.

An autonomous, closed-loop robotic system that plays Battleship using chemical color indicators and computer vision. When the system queries a position, a pH-sensitive reagent reveals a hit or miss through a color change. An onboard camera captures the grid, a computer vision algorithm samples RGB values to evaluate the outcome, and a hunt-target heuristic automatically determines the next strategic coordinate.

BATTLE_SAT

Can we detect experimental 'lies' and recover ground-truth? 

A Z3 solver that reconstructs ground-truth Battleship boards from noisy experimental readings. Constraints encode ship geometry and measurement error, so the solver returns the boards consistent with what the instrument actually saw.

Adaptable Scientific Communication for Interdisciplinary Teams

While scLIDER automates the scRNA-seq pipeline up to UMAP and clustering, cell-type annotation remains a highly researcher-dependent process. This validation study dives into the annotation logic of Doke et. al's 2022 study, which discovers a novel profibrotic Proximal Tubule cell type implicated in the profibrotic cascade. The accompanying documentation pairs a rigorous technical paper with an engaging presentation deck designed to break down dense complex scientific concepts into intuitive, visual takeaways for any audience.
